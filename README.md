# CloudPulse

CloudPulse is a cloud-native e-commerce and order monitoring platform.

## Technology Stack

- AWS
- Docker
- Kubernetes
- Ansible
- GitHub Actions
- Node.js
- MySQL
- Redis
- Amazon S3
- Amazon EKS
- Amazon ECR
- Amazon RDS
- Amazon ElastiCache
- Amazon CloudWatch
- Amazon SNS
- Route 53
- CloudFront

## Architecture

CloudPulse uses a microservices architecture with separate services for:

- Frontend
- Users
- Products
- Orders

The application will be containerized with Docker and deployed to Kubernetes on AWS EKS.

## DevOps

CI/CD will be implemented using GitHub Actions.

Infrastructure and server configuration will be automated using Ansible.

Monitoring and alerting will use Amazon CloudWatch and SNS.
